EMERSON UNIVERSITY LMS - QUICK DEPLOYMENT

LOCAL
1) server: npm install && npm run dev
2) client: npm install && npm run dev
3) seed: http://localhost:5000/api/dev/seed
4) website: http://localhost:5173/

VERCEL
- Deploy client/ as one Vercel project.
- Deploy server/ as a second Vercel project.
- Set VITE_API_URL on client to https://YOUR-BACKEND.vercel.app/api
- Set CLIENT_URL on backend to https://YOUR-FRONTEND.vercel.app
- Set MONGO_URI + JWT secrets on backend.
- For uploads set VITE_CLOUDINARY_CLOUD_NAME and VITE_CLOUDINARY_UPLOAD_PRESET on frontend.
- Set VITE_ENABLE_SOCKET=false on Vercel.
- See VERCEL_DEPLOYMENT.md for full details.
